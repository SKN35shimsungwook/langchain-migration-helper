# 데이터 출처 조사

> 조사일: 2026-10-12
> 목적: RAG에 넣을 LangChain 문서와, 테스트 코드를 뽑을 구버전 코드의 출처를 "파일로 한 번에 받을 수 있는 곳" 위주로 찾기
> 표기: ✅ 직접 열어서 확인함 / 🔎 검색 결과로만 확인함 / ❌ 확인 못 함

## 결론 요약

- **LangChain 구버전 → 신버전 변환 쌍(before/after) 데이터셋은 찾지 못했습니다.** 그래서 테스트셋 30개는 팀이 직접 만들었습니다.
- **최신 공식 문서는 파일 하나로 통째로 받을 수 있습니다** (`llms-full.txt`).
- python.langchain.com은 docs.langchain.com으로 **308 영구 리다이렉트**됩니다. 구버전(0.3) 문서는 GitHub `v0.3` 브랜치에서 받아야 합니다.

## 1. 문서 통째 덤프 (RAG용, 최우선)

| 자료 | 형식 | 버전 | 라이선스 | 받는 방법 | 확인 |
|---|---|---|---|---|---|
| [llms-full.txt](https://docs.langchain.com/llms-full.txt) | 텍스트 1개 (10MB 초과) | 최신 1.x | MIT (docs 저장소) | 직접 다운로드 | ✅ 존재 확인 |
| [llms.txt](https://docs.langchain.com/llms.txt) | 색인 (하위 색인 12개, Python 242페이지) | 최신 | MIT | 직접 다운로드 | ✅ |
| 페이지별 `.md` (예: [langchain-v1.md](https://docs.langchain.com/oss/python/migrate/langchain-v1.md)) | 마크다운 | 최신 | MIT | URL 끝에 `.md` | 🔎 |
| [langchain-ai/docs](https://github.com/langchain-ai/docs) | MDX 원본 (`src/oss/`) | 최신 | MIT | `git clone` | ✅ |
| [langchain v0.3 브랜치 docs](https://github.com/langchain-ai/langchain/tree/v0.3/docs) | MDX, ipynb (`docs/docs`) | 구버전 0.3 | MIT | `git clone -b v0.3` | ✅ |
